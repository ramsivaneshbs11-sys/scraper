🚀 Quick Start Guide

How the 5-Layer QA Pipeline operates in this workspace.

1. Knowledge Hub: Upload your PRD, API Specs (OpenAPI/Swagger), or existing manual test sheets. They are automatically extracted and indexed into Qdrant.

2. Requirements: Review extracted specifications, resolve ambiguities, and approve requirements.

3. Test Studio: Generate grounded test cases using RAG context. Edit steps, verify acceptance criteria, and export directly to Excel (.xlsx) or Gherkin.

4. Automation: Generate executable Playwright TypeScript tests mapped to requirements.
